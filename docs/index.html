      About this replay

      • Synthetic data. Clubs, players and events come from a seeded simulator. No real match data.
      • Replay, not live. The page replays a pre-built bundle. No server and no network calls.
      • Drafts come from an agent on Microsoft Foundry, run at build time. A deterministic verifier checks every claim before it can air. The replay never calls a model. Six drafts with planted errors come from a rule-based drafter, as test cases for the verifier.
      • Spanish comes from templates and a glossary and has not been reviewed by a native speaker.
      • Win probability is a simple Poisson model with stated assumptions, not a prediction about real football.
